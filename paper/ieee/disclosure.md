# AI-use disclosure (draft for the authors -- edit to the venue's policy)

During preparation of this manuscript draft the authors used the Research Communication Engine (RCE v0.4, a local
skill with deterministic checking tools) with the Claude Opus 5.5 model to build an evidence map from the project's
saved evaluation artifacts, draft sections from that map, run two blind review rounds with an isolated reviewer
instance of the same model, and check that every number traces to a saved artifact. Literature metadata was verified
against Crossref and arXiv records; cited works were read at abstract level only. Figures were rendered from saved
artifacts by the RCE renderer; no image was AI-generated. All results come from the authors' own experiments; the
authors are responsible for verifying the content before any submission.
