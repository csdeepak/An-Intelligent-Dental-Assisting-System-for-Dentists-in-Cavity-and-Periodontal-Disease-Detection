WHAT THIS IS
--------------------------------------------------------------------------------
Stage 4a of the pipeline. ResNet18 (ImageNet-pretrained, fc 512 -> 2) over a
1.5x width / 2.0x height expanded tooth crop at 224x224, predicting bone loss
present / absent. It is DEF_BONE_LOSS in scripts/run_inference.py.

Trained April 2026 from notebooks/bone_loss/. This file was written on 27 Aug
2026 to freeze and tag weights that had been in use, and depended on, for months
without a version tag or a recorded hash -- the last untagged models in the
project (models/README.md "One gap remains"). Nothing was retrained; the bytes
are the April artifacts, now pinned.

CLASS ORDER — the one thing to get right, now confirmed rather than assumed
--------------------------------------------------------------------------------
src/classifiers.py declares BONE_LOSS_CLASSES = ["normal", "bone_loss"], i.e.
index 0 = normal, index 1 = bone_loss. The checkpoint carries no class_to_idx, so
until 27 Aug 2026 run_inference.py's meta block described this order as
"Inferred, not read."

It is now CONFIRMED, two independent ways that agree:

  1. FocalLoss alpha is inversely proportional to class frequency.
       alpha ratio  2.258 / 0.642 = 3.5171
       count ratio  2,500 /   711 = 3.5162
     These agree to 0.03%, so index 0 is the MAJORITY class = normal.

  2. training_summary.txt, written by the training run itself, labels its own
     per-class scores "F1 Normal (cls 0)" and "F1 Diseased (cls 1)".

Evidence (1) is an arithmetic property of the config; evidence (2) is a direct
statement from the run. If the order were flipped, the pipeline would report bone
loss on ~99% of teeth rather than the 0.7% observed on DENTEX -- a third, weaker
corroboration from in-situ behaviour.

KNOWN LIMITATION — this model does not generalise, and that is measured
--------------------------------------------------------------------------------
0.9233 macro-F1 in domain (Tufts) collapses outside it:
  - DENTEX:   fires on 0.7% of detected teeth
  - Ningxia:  0.8-5.4% affected-tooth sensitivity, across 4 hospitals
Two independent external datasets agree. This is the project's one open technical
failure (transfer.md 1). Do not quote 0.9233 without the out-of-domain figures.
